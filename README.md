# Kian Kang - 3D World Models & Spatial Intelligence

An independent research and production portfolio exploring how world-model understanding can become structured, editable and verifiable real-time 3D production systems.

Live portfolio: https://k-k-ing.github.io/kian-worldmodel-portfolio/en/

## Core projects

- **WORLDIR**: scene understanding, spatial evidence, traceable scene decisions and deterministic compilation experiments.
- **MATE**: an artist-facing asset and material iteration prototype. The WORLDIR-to-MATE connection is an architectural direction, not a completed automatic integration.
- **Spatial experiments**: camera registration, Gaussian/PLY queries, dense mesh reconstruction and constrained asset fitting.
- **Production systems**: generative asset workflows, Blender/Unreal integration and editor automation.

Demonstrated workflows, unresolved experiments, proposed architecture and future directions are labeled separately. Visual reconstruction is not presented as production geometry or calibrated spatial truth.

## Site structure

Static HTML, CSS and JavaScript; no build dependencies. The specialized English homepage is `en/index.html`, with project archives under `en/projects/` and the updated two-page resume at `en/resume-source.html`. Shared visual assets live under `assets/`.

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps the static assets unchanged. Open `/en/` for the new specialized portfolio; the copied Chinese pages remain available at the root.

This project is separate from the original portfolio at https://k-k-ing.github.io/kaixin-technical-art-portfolio/. The original repository and its Chinese and English sites are preserved.

Local deployment archives, QA output and internal evidence inventories are excluded from version control. Project imagery and video are real prototype evidence, not generated replacements.
